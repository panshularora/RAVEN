# RAVEN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a runnable RAVEN demo: leak alarm → navigate → inspect → IK valve turn → DONE, with a human-assist path, on a Python mock and optionally CoppeliaSim.

**Architecture:** One Python mission FSM talks to a `RobotBackend`. Mock backend + matplotlib prove the loop; Coppelia ZeroMQ backend reuses the same FSM. Numbers live in `raven/config.py`.

**Tech Stack:** Python 3.13, numpy, OpenCV, matplotlib, pytest; optional `coppeliasim-zmqremoteapi-client` (ZMQ port 23000).

**Spec:** `docs/superpowers/specs/2026-10-30-raven-design.md`

## Global Constraints

- Default tests never import or require CoppeliaSim; `python -m pytest tests -q` is the suite.
- All plant/robot numbers come from `raven/config.py` (spec §4); no duplicated magic numbers in other modules.
- CLI: `python -m raven`, `python -m raven --backend coppelia`, `python -m raven --fail-valve`.
- Coppelia ZMQ default port 23000; scene names `/RAVEN`, `/RAVEN/base`, `/RAVEN/arm/j1`–`j5`, `/RAVEN/gripper`, `/RAVEN/camera`, `/Plant/tank`, `/Plant/valve`.
- Coppelia not running: print `Start CoppeliaSim Edu, then retry --backend coppelia` and exit 1; no traceback.
- Valve closed iff angle in [80, 100] degrees; leak clears only when closed.
- Dependencies: numpy, opencv-python, matplotlib, pytest; optional coppeliasim-zmqremoteapi-client.
